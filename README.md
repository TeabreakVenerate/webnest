# webnest

High-converting storefront builder and productized web design agency platform for Nigerian campus vendors, boutique owners, and micro-merchants.

## Core Value Proposition
- Turn WhatsApp status and messy DMs into a 1-click order store in 48 hours.
- Flat ₦10,000 base fee with free lifetime static hosting (Vercel & Cloudflare).
- 0% sales commission. Direct bank transfers.

## Features & Architecture
- **Next.js 15 App Router** + React 19 + Tailwind CSS
- **Interactive Pricing Calculator**: Dynamic live total in NGN (₦) with Pro Vendor Bundle switcher and instant WhatsApp URL payload generator.
- **Modular Capabilities Bento Grid**:
  - Multi-item Cart Drawer (+₦5,000)
  - Order Tracking Admin Table (+₦10,000)
  - Self-Serve Inventory CMS (+₦15,000)
  - Custom Domain Setup (+₦7,500)
  - Traffic & Click Analytics (+₦5,000)
- **Proof of Work Showcase**: Highlighting real systems engineered by Endurance Owie (Elikar, Light Pen Hub, Campus Pastry).
- **Referral Engine**: Embeddable client footer snippet.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
