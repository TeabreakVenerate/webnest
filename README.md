# webnest

High-converting storefront builder and productized web design agency platform for business owners, freelancers, and vendors.

## Core Value Proposition
- Turn WhatsApp status and messy DMs into a 1-click order store in 72 hours or less.
- Flat ₦25,000 base fee with free lifetime static hosting (Vercel), multi-item cart drawer, and backend inventory tracking included.
- 0% sales commission. Direct WhatsApp checkout routing.

## Features & Architecture
- **Next.js 15 App Router** + React 19 + Tailwind CSS
- **Interactive Pricing Calculator**: Dynamic live total in NGN (₦) with Pro Bundle switcher and instant WhatsApp URL payload generator.
- **Modular Capabilities & Add-ons**:
  - Multi-item Cart Drawer (Included in Base)
  - Backend Inventory Tracking & Management (Included in Base)
  - Order Tracking Dashboard (+₦12,500)
  - Google Search Console & Indexing (+₦7,500)
  - Advanced Keyword Ranking & Schema (+₦15,000)
  - Visitor Traffic Analytics (+₦7,500)
  - Custom Domain Setup (+ Varies)
- **Proof of Work Showcase**: Highlighting real systems taking orders (Elikar Essentials).
- **Referral Engine**: Embeddable client footer snippet.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
